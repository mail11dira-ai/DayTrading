description: Weekly review — write weekly.md from the past week's notes
---

Write the weekly review of this knowledge base. Follow the rules in `CLAUDE.md`.

Read the past 7 days of `daily/`, the wiki pages changed this week, and the week's
additions to `raw/`. Then write `weekly.md` with these sections, each item linked to
its page and source:

1. **Ideas that keep coming back**
2. **Notes that contradict each other** — show both sides
3. **Promises still open**
4. **3 things worth thinking about next week**

If `weekly.md` already holds an earlier week, move that content to
`daily/weekly-YYYY-MM-DD.md` first instead of overwriting it.
